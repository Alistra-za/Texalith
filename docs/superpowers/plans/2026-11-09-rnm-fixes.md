# RNM fixes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix the 9 minor findings that plan 3's final review deferred, so the RNM tab reports every failure it meets, shows the base the user opened last, holds one decoded base in memory, records only the inputs the blend used, and keeps its own scroll position.

**Architecture:** Almost every change is in `src/rnm/tab.rs`. Task 1 fixes how files are opened, Task 2 fixes the tab's state, Task 3 fixes two UI details (one of them shared with `src/tab.rs`), and Task 4 widens the engine-equivalence test. No new modules, types or dependencies.

**Tech Stack:** Rust 1.99, edition 2021, eframe/egui 0.36.2, egui_kittest 0.36.2, `std::panic::catch_unwind`. Tests use `engine::rnm` and `engine::presets` (Tessalith, read-only).

**Spec:** the deferred-minor list from plan 3's final review, in `docs/superpowers/plans/2026-11-08-rnm-tab.md` (its spec sections still apply) and in the project memory. The 9 items:

1. A dead blend thread is silent.
2. Both columns share one ScrollArea id, so a scroll position carries across tabs.
3. Two bases opened close together can leave the older one shown.
4. The `_msn` refusal runs after the full load.
5. The raw base image stays in memory after `decode_base` (about 268 MB at 4096).
6. Clearing a layer leaves its mask, and AO is recorded with no bent layer.
7. A load-thread panic is silent.
8. The same error shows in two colours.
9. The engine-equivalence test has no bump mask.

## Review Focus

1. A base opened while an earlier base is still loading, where the earlier one finishes last: the base opened last is shown. Test: Task 1, `the_last_opened_base_wins`.
2. A blend thread that dies with a job outstanding: the status says so. Test: Task 2, `a_dead_blend_thread_is_reported`.
3. A layer cleared after its mask was filled: the mask goes with it, so a later Save does not record a mask the user cannot see. Test: Task 2, `clearing_a_layer_clears_its_mask`.
4. An AO map filled with no bent layer: the marker does not record it. Test: Task 2, `ao_is_recorded_only_with_a_bent_layer`.
5. A visit to the From normal tab: the RNM column's scroll position survives it. Test: Task 3, `the_rnm_column_keeps_its_own_scroll`.

/// Saves into `out` and returns the input keys the marker recorded.
fn recorded(h: &mut Harness<'_, RnmTab>, out: &Path) -> Vec<String> {
    h.state_mut().folder = Some(out.to_path_buf());
    settle(h);
    press(h, "Save");
    let m = marker::read(&std::fs::read(out.join("rock_n.png")).unwrap()).unwrap();
    m.settings["inputs"].as_object().unwrap().keys().cloned().collect()
}

#[test]
fn ao_is_recorded_only_with_a_bent_layer() {
    let d = temp("ao-marker");
    let b = base(&d, "rock_n.png");
    layer(&d, "rock_detail.png");
    let ao = layer(&d, "occlusion.png");
    let bent = layer(&d, "curved.png");
    let mut h = rig();
    open(&mut h, &b);
    let ctx = h.ctx.clone();
    h.state_mut().fill(Slot::Ao, ao, &ctx);
    settle(&mut h);
    let without = recorded(&mut h, &temp("ao-marker-1"));
    assert!(without.contains(&"detail".to_string()) && !without.contains(&"ao".to_string()), "{without:?}");
    h.state_mut().fill(Slot::Layer(LayerId::Bent), bent, &ctx);
    settle(&mut h);
    let with = recorded(&mut h, &temp("ao-marker-2"));
    assert!(with.contains(&"ao".to_string()), "{with:?}");
}
