# RNM tab Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The RNM tab: open a base `_n` or `_cnr` normal, fill five layer slots (bent, bump, bump2, detail, detail2) with optional masks and an AO map for bent, blend them in a visible order, see the result in the 2D view and the 3D preview, and save one marked 16-bit RGBA PNG that keeps the base's alpha and never replaces the base.

**Architecture:** Tasks 1-3 are library code with no UI, and a reviewer can stop after them. `src/rnm/blend.rs` copies Tessalith's blend math and replaces its `apply(work, &RnmJob, &Profile)` with one that takes images already in memory and Texalith's own `Settings`. An engine-equivalence test pins the copy. Task 4 adds a generation thread where the newest job wins, in the pattern of `from_normal::worker`. Images load once, when a slot is filled, off the UI thread; each job carries `Arc`s, so a slider tick never reads a file. Tasks 5-6 add the RNM column and a tab bar above the left column. The save path reuses `save::review`, `Review::write` and the overwrite dialog, which moves out of `Tab` so both tabs share it.

**Tech Stack:** Rust 1.99, edition 2021, eframe/egui 0.36.2, egui_kittest 0.36.2, `rfd` 0.17.2, rayon, `engine::load::load_image`, Texalith's `marker`, `export`, `save`, `resample` and `view2d` modules. Tests use `engine::rnm` and `engine::presets` (Tessalith, read-only) for the equivalence check.

- Produces, in `src/rnm/mod.rs`:
  - `#[derive(Clone, Copy, PartialEq, Eq, Hash, Debug, Serialize, Deserialize)] #[serde(rename_all = "snake_case")] pub enum LayerId { Bent, Bump, Bump2, Detail, Detail2 }`, with `LayerId::ALL: [LayerId; 5]` in that order, `fn is_bump(self) -> bool`, `fn name(self) -> &'static str` (the display names above) and `fn default_strength(self) -> f32` (0.35, 0.4, 0.4, 0.6, 0.3). Arrays below are indexed by `id as usize`.
  - `#[derive(Clone, Copy, PartialEq, Debug, Serialize, Deserialize)] pub struct Layer { pub strength: f32, pub flip: bool }`. For bump layers `strength` is `k`.
  - `#[derive(Clone, PartialEq, Debug, Serialize, Deserialize)] pub struct Settings { pub order: [LayerId; 5], pub layers: [Layer; 5], pub use_ao: bool, pub ao_power: f32 }` with `Default` from the Global Constraints.
  - `#[derive(Clone, Default)] pub struct Inputs { pub layers: [Option<Arc<Rgba32F>>; 5], pub masks: [Option<Arc<Rgba32F>>; 5], pub ao: Option<(Arc<Rgba32F>, usize)> }`. The `usize` is the AO channel.
- Produces, in `src/rnm/blend.rs`:
  - `pub fn decode(c: [f32; 4], s: f32, flip: bool) -> [f32; 3]`, `pub fn rnm(base: [f32; 3], detail: [f32; 3]) -> [f32; 3]`, `pub fn bump_normals(img: &Rgba32F, k: f32) -> Rgba32F`: copies of Tessalith's, same formulas.
  - `pub fn decode_base(img: &Rgba32F) -> Rgba32F`: `x = 2r − 1`, `y = 2g − 1`, `z = sqrt(max(0, 1 − x² − y²))`, alpha kept. Rebuilding z always makes a two-channel base (B = 0) work.
  - `pub fn encode(work: &Rgba32F) -> Vec<[f32; 4]>`: `(v + 1) / 2` per RGB, alpha kept.
  - `pub fn apply(work: &mut Rgba32F, inputs: &Inputs, s: &Settings)`: Tessalith's `apply` with the file loads replaced by `inputs`. Same steps: renormalise the base first; skip empty slots; bump layers `resample(bump_normals(img, k))`, flip, then a mask scales the slope; bent `decode(src, 1, flip)` blended by `bent_weight(s, ao_power, ao[i], m)` when `use_ao` and an AO is present, otherwise `s · m`; other layers `decode(src, s · m, flip)` then `rnm`. Masks read channel 0, AO reads its channel; both clamped to 0..1. Alpha is never written. Per-pixel loops may use rayon's `par_iter_mut`.
  - Private `unit` keeps Tessalith's rule exactly: divide when the length is above 1e-8, otherwise `(0, 0, 1)`.

  - `#[derive(Clone, Copy, PartialEq, Eq, Debug)] pub enum Suffix { N, Cnr }`, and `pub fn suffix(base: &Path) -> Suffix`.
  - `#[derive(Default, Debug, PartialEq)] pub struct Found { pub layers: [Option<PathBuf>; 5], pub masks: [Option<PathBuf>; 5], pub ao: Option<PathBuf> }`.
  - `pub fn siblings(base: &Path) -> Found`: scans the base's folder for image files whose `layer_of` stem equals `stem(base)`, ignoring case. A prefixed term counts only when it matches the base's suffix, and it beats the unprefixed term. `<stem>_ao` fills `ao`. When two files differ only by extension, take the one whose extension comes first in `tab::EXTENSIONS` (make that `pub(crate)`).
  - `pub fn refuse(path: &Path, size: (u32, u32)) -> Option<String>`: the `_msn` line when the stem ends `_msn` (any case), the size line when a side is above `MAX_SIZE`, otherwise `None`.

Eye normals are refused only when they are named `_msn`. Texalith has no shader to tell an eye normal from another one, and it leaves correct use to the person using it.

  - `pub fn new(jobs: Sender<Job>, replies: Receiver<Arc<Output>>) -> RnmTab`.
  - `pub fn open_base(&mut self, path: PathBuf, ctx: &egui::Context)`: loads on a thread, as `Tab::start_open` does. On arrival, it checks `files::refuse`; a refused base sets the status error and leaves every field as it was. Otherwise it clears the slots, the outputs and any pending review, keeps `settings`, sets `folder` to the base's folder, and calls `fill(slot, path)` for each path `files::siblings` finds.
  - `pub fn fill(&mut self, slot: Slot, path: PathBuf, ctx: &egui::Context)`: loads on a thread. On arrival it stores the `Loaded` and submits a job. On failure the status reads `"Could not read {file}: {error}"` and the slot stays empty.
  - `pub fn clear(&mut self, slot: Slot)`, `pub fn move_layer(&mut self, id: LayerId, up: bool)`, `pub fn submit(&mut self)`, `pub fn drain(&mut self) -> bool` (true when new outputs arrived), `pub fn draw_column(&mut self, ui: &mut egui::Ui)`.
  - Save is enabled only when a base is open, `outputs.id == jobs_sent`, no load is pending, and `!files::collides(base, folder)`. It plans one `(MapKind::Rnm, Planned { path: folder.join(files::out_name(base)), bytes: rnm_png(..) })`, then follows `Tab::save`: run `save::review`, open the dialog when `needs_dialog`, otherwise write. The status reads "Saved {file} to {folder}" or "Nothing to save: {file} in {folder} already matches".

Column layout, top to bottom:
1. "Open base…" and the base's file name, truncated with the full path on hover. With no base, the empty-state line and nothing else.
2. One block per layer, in `settings.order`: the layer name; the slot's file name or "None"; "Choose…" and "✕". When the slot is filled, it shows the Depth (bump layers, as "0.80 texels") or Strength slider with its reset button and help, then "Where it applies" with its own Choose and Clear and its help.
3. The fixed line "Alpha is kept as it is."
4. A collapsed "Advanced" section: the Order rows with ▲ and ▼ and the Order help; Flip this layer for each filled layer, with its help once; Bend mostly in shadows with its help, the "AO map" slot with Choose and Clear, and the Focus on crevices slider with its reset and help.
5. In the bottom sub-panel: the folder row (as in the From normal column), the collision line when `collides`, the status, and Save.

A slider sends a job on every change; the worker drops stale ones. The AO map is read from its red channel (`Inputs::ao` channel 0).
